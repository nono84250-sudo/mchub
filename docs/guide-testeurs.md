# Guide des testeurs Omniscient Launcher (brouillon)

## 1. Installer la version bêta
1. Va sur la page des versions du launcher sur GitHub (nono84250-sudo/omniscient-launcher).
2. Télécharge `OmniscientLauncherSetup.exe` de la dernière **pré-version** (celle marquée « Pre-release »).
3. Lance l'installeur. Windows peut afficher un avertissement de sécurité : l'installeur n'est pas encore signé.

## 2. Activer le canal bêta
1. Ouvre le launcher, puis Paramètres → Divers.
2. Coche « Canal bêta » et redémarre le launcher.

## 3. Tester
- Connecte-toi avec ton compte Microsoft.
- Ouvre un serveur, puis lance le jeu.
- Vérifie que tes modifications de config ne sont pas écrasées au lancement suivant.
- Ouvre le panneau « Statut des services » : le test de connexion doit se terminer.

## 4. Signaler un problème
- Décris ce que tu faisais, ce qui s'est passé, et le serveur concerné.
- Joins le rapport de diagnostic (Paramètres, export de diagnostic) : il contient la version et le journal.
- Envoie le tout au canal de retours (à définir : forum ou formulaire).

## 5. Ce qu'il ne faut pas faire
- Ne partage pas ton jeton de connexion ni le fichier de compte.
- Ne télécharge pas de version qui n'est pas celle de la page officielle.

_Brouillon : à compléter quand le canal de retours et la version de test seront choisis._
