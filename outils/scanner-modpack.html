Scanner de modpack CurseForge → Modrinth

Outil de test local. Dépose un pack CurseForge : la page cherche chaque mod sur Modrinth et dit combien elle en retrouve. Les fichiers restent sur ton PC, seule l'API publique de Modrinth est appelée.

1. Le pack

Glisse ici l'export CurseForge (.zip), le dossier mods du pack, ou des fichiers .jar

Aucun fichier choisi.

Le plus fiable : le dossier mods du pack installé (dans l'app CurseForge : clic droit sur le profil → « Ouvrir le dossier »). Un export .zip seul ne contient souvent que des numéros : la page lit alors la liste modlist.html si elle est dedans.

Si le .zip contient manifest.json, ces champs se remplissent tout seuls.

Comment la page décide

  • Identique le même fichier existe sur Modrinth (même empreinte). Arrive souvent : beaucoup d'auteurs publient le même .jar sur les deux sites.
  • Trouvé même mod trouvé par son identifiant ou son nom, avec une version pour cette version de Minecraft et ce loader.
  • Pas pour cette version le mod est sur Modrinth, mais pas pour cette version de Minecraft ou ce loader.
  • Introuvable rien de sûr sur Modrinth : à mettre à la main.

« Trouvés » dans le bilan = Identique + Trouvé. Un nom proche mais pas sûr n'est jamais compté comme trouvé.
